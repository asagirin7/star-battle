# Star Battle ✦

スマホで遊べる、日本語の Star Battle。各行・各列・各色のエリアに星を1つずつ置き、星同士は斜めを含めて隣接させないロジックパズルです。

- 6×6 / 7×7 / 8×8。次の問題を選ぶたび、その場で新しい問題を自動生成。固定の問題数に上限はありません。
- 全問題でエリアの連結性と解の一意性を確認し、既存の盤面と重複しない問題をDBに保存。
- **残機3つがそのままスコア**。誤った場所に星を置くと残機が1つ減ります。
- ノーミスでクリアすると3点、1ミスで2点、2ミスで1点。3ミスでゲームオーバーになり、その問題は0点です。
- クリアするたびにスコアを累計し、ランキングに反映。遊ぶほど積み上がります。盤面サイズによる倍率はありません。
- 正解の星・ミス数・残機・クリアをサーバーで判定・保存。リロード、メモを戻す、複数タブ、通信の再送でも残機が復活したり二重加点したりしません。
- FastAPI + SQLAlchemy + Alembic + PostgreSQL。フロントエンドはHTML/CSS/JavaScriptで、ビルド不要。

## 操作

「★ 星」を選び、マスをタップして星を置きます。正解の星は固定されます。「× メモ」ではタップで除外メモを付け外しできます。メモモードのダブルクリックと右クリックでも星を置けます。

「メモを戻す」「メモを消す」はメモだけに作用します。正解の星・ミス・残機は変わりません。「次の問題」「新しい問題に挑戦」で新しい盤面に進みます。生成に失敗した場合は元の盤面で再試行できます。

リロードすると難易度ごとの最新の盤面に戻ります。クリア済み・ゲームオーバーの盤面も次の問題へ進むまでは保持します。途中のメモはlocalStorage、確定した星と残機はDBに保存します。

## Kamui にデプロイ

[Kamui Python 構成](https://docs.kamui-platform.com/ja/gui/apps/python.html)に従い、リポジトリルートを実行ディレクトリにしてください。資料の `python/main.py` の例に対し、本リポジトリではルートで `python main.py` を実行する構成です。

| 設定 | 値 |
|---|---|
| 実行ディレクトリ | リポジトリルート |
| セットアップコマンド | `pip install -r requirements.lock` |
| 起動前コマンド | `alembic upgrade head` |
| アプリ起動コマンド | `python main.py` |
| Python | 3.12以上 |
| ヘルスチェック | `/health` |

1. 公開リポジトリを接続し、Python アプリを作成。
2. PostgreSQL データベースを作成し、アプリで選択。
3. 上記コマンドを指定。HTTPSでは環境変数 `COOKIE_SECURE=true` を追加。
4. デプロイ後、アプリURLからプレイヤー名を登録して遊べます。

`PORT` に従って `0.0.0.0` で Uvicorn を起動します。DB 接続は `DATABASE_URL` を優先し、未指定時は `DB_HOST / DB_PORT / DB_NAME / DB_USER / DB_PASSWORD` を使用します。どちらもない場合は開発用 SQLite に接続します。本番の記録には PostgreSQL を利用してください。

`.env.example` は設定例です。アプリは `.env` を自動読込しないため、環境変数として設定してください。

既存版からは同じ `alembic upgrade head` で更新できます。プレイヤーとクリア履歴を引き継ぎ、旧ルールの100/180/280点はノーミス相当の3点に統一します。旧固定問題の途中盤面は、新しい自動生成の問題へ切り替わります。

## ローカル起動

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.lock
alembic upgrade head
python main.py
```

http://localhost:8000 で開きます。SQLite は `star-battle.db` に保存します。

## プレイヤーと記録

プレイヤーは推測困難なトークンを HttpOnly / SameSite=Strict Cookie に保存し、DBにはそのハッシュのみを記録します。名前は識別子ではないため同名も登録できます。パスワードやメールは不要です。**別端末への引継ぎ・Cookie削除後の復旧には対応していません。** ランキングには名前と累計スコア・クリア数が公開されます。

履歴の時間は問題を開始してからクリアまでの実時間で、閉じている間も含みます。速度ボーナスはありません。ランキングは累計スコア、クリア数、プレイヤーIDの順。上位100人と自分の累計スコアを表示します。

難易度は盤面サイズによる区分です。問題は解の一意性を検証し、答えはブラウザへ送りません。生成には時間制限を設けており、時間内に作成できない場合は再試行を案内します。カジュアルなゲームを想定しており、自動解答や複数アカウントの抑止は含みません。

## 検証

```sh
pip install -r requirements-dev.txt
pytest -q
alembic upgrade head
alembic check
playwright install chromium
# 別ターミナルでアプリを起動してから
python scripts/browser_smoke.py
python scripts/concurrency_smoke.py
```

APIテストは残機別の1/2/3点・3ミスで終了・連続出題と累計・一意解とエリア連結性・再送・他人のゲームの拒否を検証します。ブラウザテストは320/390/1280pxでメモ操作、ミスと確定した星の復元、クリア、ランキング、次の問題、ゲームオーバーを確認します。並列検証は8件の同時送信で残機・単回加点を確認します。CIではPostgreSQLを使います。
